**ECG Classifier — AI-Assisted ECG Analysis**

Building on my earlier academic ECG Holter prototype, this project explores how deep learning could help facilitate ECG interpretation. The initial idea came from the challenge of reviewing long-duration Holter recordings and the potential for AI to help highlight data requiring closer examination.

The current implementation classifies individual ECG images as **Normal or Abnormal** using MobileNetV2, with a FastAPI backend and an ASP.NET Core web interface.

🔗 **[Try the live demo](https://ecg-classifier-bys-a-yloo.onrender.com/)**  
📂 **[Explore the source code](https://github.com/Sihame-health/ecg-classifier-byS.A)**
